# Tic Tac Toe — React Edition

A beautifully animated, client-side Tic Tac Toe game built with **React 19** and **Vite**. Play against a friend locally with smooth SVG animations, dark/light theme toggle, score tracking, and move history.

## Features

- **SVG Animations** — Smooth draw-in animations for X, O, and winning line highlights
- **Dark/Light Mode** — Toggle with localStorage persistence
- **Score Tracking** — Tracks wins, losses, and draws across multiple rounds
- **Move History** — Full chronological log of every move
- **Responsive Layout** — Works on desktop and mobile
- **Zero Dependencies** — No external UI libraries, pure React + CSS

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
